# Rainkeeper — Assignment 3

A libGDX rain-catching game with a main menu, help page, gameplay screen, and results screen. Collect blue and gold rain while avoiding red hazards.

**Start here: [README.txt](README.txt)** — complete rules, controls, class explanations, build instructions, and credits.

## Run

Use JDK 17 or newer. From the project folder:

```text
gradlew.bat lwjgl3:run
```

On macOS/Linux: `sh gradlew lwjgl3:run`.

## Check and build

```text
gradlew.bat core:check lwjgl3:fatJar
```

This project extends the previous Rainkeeper game with separate classes and screen navigation for CSA Assignment 3. Code, documentation, and the existing custom assets were prepared with AI assistance.
